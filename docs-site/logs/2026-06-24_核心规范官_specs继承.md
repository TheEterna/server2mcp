## 发现（风险点 / 技术债 · 需 CEO 复核）

1. **R2 启动断言缺口（真实）**：本框架解析器靠 `@ConditionalOnParser` 配置激活，但 `Conditions.ParserCondition` 对配置的 parser 名**无"已知集合"校验**——拼错（如 `JAVADOCS`）会静默不激活，零告警。我在 REGISTRATION_DISCIPLINE V-2 如实标注为当前缺口，列为限期补齐项（非红线），未捏造已有断言。**这是真实可改进点，建议 CEO 评估是否立项修复**（属全局/协议层改动，动工需董事长批准）。
2. **R4 裸 string（真实）**：`@ConditionalOnParser.value()` 是 `String`（V-7），拼错编译器零报错。改枚举属 SDK 公开 API 破坏性变更，须董事长批准协议变更——已标注，未擅改。
3. **三方协议引用悬空处理**：source REGISTRATION_DISCIPLINE 大量引用 real-agent 的 SUBAGENT_PROTOCOL_SPEC / VOLO_AI_PROTOCOL 等姊妹文档，本项目无对应物——我**未保留这些悬空链接**，改为引用本项目真实类的 file:line，避免捏造。
