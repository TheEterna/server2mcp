# 一、做了什么（What）

为 api2mcp4j（纯 Java 库 / Spring Boot Starter）从零搭建精炼版 `.claude/` 团队基建，继承自姊妹项目 `../real-agent` 但裁剪为 Java 库适配：

1. **10 个 agent 定义**（`.claude/agents/*.md`），全部面向 Java 17 / Spring Boot Starter / Spring AI / MCP SDK 语境
2. **agent-groups.json** — 三分组注册表（command 2 / execution 4 / quality 4）
3. **scripts/agent-groups.mjs** — list/find/verify/stats 验证脚本（verify 双向一致 + 不一致时 EXIT=1）
4. **session-start hook**（`.claude/hooks/session-start.sh` + `.claude/hooks.json`）— 轻量版，输出模块清单 + 自决协议 / 三方制衡 / 心法位置
5. **task.json** — 简化版物理模块注册表（6 模块）+ global_rules / specs / authority

# 二、为什么这么做（Why）

- real-agent 有 82 个 agent，多为前端 / 设计 / PM（Vue / GSAP / Design Token / DDD 四层 / 响应式），对纯 Java Starter 库无实效 → 剥离主体，仅保留 10 个对库有实效的核心 agent
- 保留内核：三方独立制衡（架构师 / 御史台 / CEO）+ 注册纪律（Rule #12）+ 心法驱动（呼应 docs/rules/global、docs/specs）
- 御史台保留"两阶段审查 + 严重度校准 + 反罗织"灵魂，剥离过重动漫人格，7 维度从前端（可访问性 / 暗色模式）替换为 Java 库维度（依赖方向 / 非侵入性 / 破坏性删除防护 / SNAPSHOT 兼容）

# 三、怎么做的（How）

- 先研读 real-agent 的 agent-groups.mjs（ROOT 定位逻辑 + 双向校验）、session-start.sh（JSON 协议）、frontmatter 风格、imperial-censor 内核、本项目 CLAUDE.md 全文
- 验证脚本相对 real-agent 的**改进**：verify 在发现不一致时 `process.exit(1)`（原脚本即使有 error 也 EXIT=0，无法用于 CI 门禁），并把"文件未收录"从 warning 升级为 error，确保严格双向一致
- 全程绝对路径，agent 线程 cwd 在 bash 调用间会重置

# 四、验证结果（Verify）

- `node scripts/agent-groups.mjs verify` → **EXIT=0**，双向一致：10 注册项 = 10 .md 文件
- `stats` → command 2 / execution 4 / quality 4 = 10
- `python3 -m json.tool` → task.json / hooks.json / agent-groups.json 三者均合法
- `session-start.sh` 实测 → EXIT=0，stdout 合法 JSON，stderr 空
- `find 解析器` → 正确命中 core-developer / test-engineer
